# Animation Framework Rules

- **GSAP**: Complex marketing animations (timelines, hero cinematic sequences, SVG morphing, advanced pinned scroll animations).
- **Motion (Framer Motion)**: UI and component transitions (page transitions, dialogs, drawers, layout animations, presence, filter shifts).
- **Lenis**: Smooth page scrolling (viewport momentum, wheel smoothing).
- **CSS**: Simple hover, fade, and transition effects (button hovers, color changes, standard transitions).
