# XYZ Buying House — SEO Strategy

## 1. Primary SEO Goal

Attract international apparel buyers searching for Bangladesh sourcing, apparel manufacturing, buying houses, garment sourcing, product development, and related services.

Do not use misleading claims or keyword stuffing.

## 2. Core Pages

Optimize:
- Home
- About
- Services
- Products
- Capabilities
- Quality
- Compliance
- Sustainability
- Factories
- Insights
- Contact

## 3. Metadata

Every public page should have:
- unique title
- unique meta description
- canonical URL
- Open Graph metadata
- social sharing image

## 4. Technical SEO

Implement:
- sitemap.xml
- robots.txt
- clean URLs
- canonical URLs
- semantic HTML
- image alt text
- responsive design
- fast loading
- structured data where appropriate

## 5. Structured Data

Potential types:
- Organization
- WebSite
- BreadcrumbList
- Article for genuine insight articles

Only use schema types that accurately describe the page.

## 6. Content Strategy

Useful future topics:

```text
Bangladesh apparel sourcing
How apparel production works
Quality control in garment manufacturing
Fabric sourcing guide
Understanding garment sampling
Bangladesh garment manufacturing capabilities
Sustainable apparel sourcing
```

Content must be genuinely useful, not AI-generated keyword filler.

## 7. International Audience

Potentially support:
- English initially
- additional languages later if commercially justified

## 8. Images

Use descriptive filenames and meaningful alt text.

Do not stuff keywords into alt text.

## 9. Buyer Trust SEO

Strong trust signals include:
- real company information
- genuine factory/capability information
- verifiable certifications
- clear contact details
- real case studies
- real production expertise

Never publish fake buyer logos or certifications.
